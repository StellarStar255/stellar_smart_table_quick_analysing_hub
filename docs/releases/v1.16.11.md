新增与 Stellar Smart Terminal 同系列的主题配色，以及可自由搭配的控件皮肤。

- **六套主题**：深蓝、暗夜紫、琥珀、午夜黑、浅色和粉红，另可选择跟随系统。入口为「视图 → 外观 → 主题」。
- **三种皮肤**：标准、圆润和紧凑；紧凑模式减少控件和表格行的留白，并保留当前缩放设置。入口为「视图 → 外观 → 控件皮肤」。
- **即时生效与记忆**：多个文档窗口同步切换，新窗口及后续打开的对话框自动使用当前外观，重启后保留设置。
- **公式与分析界面适配**：公式文字、引用区域高亮、补全纠错弹层和 Python 语法高亮随背景调整，保证浅色与深色主题中的可读性。
- **保留工作簿内容**：切换外观不改变单元格填色、数据、公式、撤销记录或正在编辑的草稿；同时修复未激活的公式提示层意外显示并遮挡表格的问题。
