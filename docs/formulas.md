# 公式输入助手

单元格输入 `=` 后可以选择常用函数。继续输入 `=SU` 会列出 SUM、SUMIF、SUMIFS；也可以输入 `=求和` 按中文用途查找。输入普通文字、单元格地址或引号中的文本时不会出现函数候选。

拼写有误时也会自动显示相近函数：例如输入 `=SUMM`，无需先输入左括号或按回车，就会看到 SUM 的拼写建议和「应用建议」按钮。Tab 或点击候选可以接受补全，建议不会自动改写输入。提示使用跟随当前窗口的浮层，窄窗口中可滚动查看，继续输入算术表达式时也会保留操作引导。

- **↑ / ↓**：选择候选；**Tab**：插入所选函数，并开始填写参数。
- **Enter**：检查并提交公式。语法未完成时保留输入，显示问题及修正建议。
- **Esc**：先收起助手，再按一次取消本次编辑。
- **F1**：编辑公式时打开函数库。也可点击主工具栏 **fx** 或「编辑 → 插入函数」。
- **F4**：循环切换引用 `A2 → $A$2 → A$2 → $A2 → A2`。

候选收起后，Tab 恢复为提交并移动到下一格。原有 Enter、Shift+Enter、Ctrl+Enter 填充选区以及点选/拖选引用操作继续可用。macOS 的 Control 菜单快捷键由 Qt 映射为 Command。

## 参数与引用

输入函数名和左括号后，助手显示完整语法、当前参数的含义和可参考的示例。光标移回前面的参数时，提示同步变化；嵌套函数优先显示最内层调用。逗号出现在双引号文本中时不会被误认为参数分隔符。

例如输入 `=IF(B2>=60,` 后，助手解释「成立时的值」；完整公式可写为：

```text
=IF(B2>=60,"及格","不及格")
```

编辑期间，引用区域在表格中显示彩色边框，并在助手里显示同色地址。重复引用同一位置使用相同颜色。大区域仅绘制当前可见部分，不会逐格扫描。

第 1 行为表头，数据从第 2 行开始。例如 B2 表示 B 列第一条数据。

## 错误与修正

助手区分「尚未写完」和「明确错误」。`=SUM(` 显示温和的未完成提示；`=SUMM(B2:B10)` 会提示可能想使用 SUM，并提供「应用建议」。缺少右括号、多余括号、参数数量不符、空参数和中文标点都有相应说明。建议只有在点击后才生效；不会自动改写原公式或引号中的文本。

合法公式仍可能因数据而出错，例如除以零、查找无匹配、区域大小不一致。这类公式可以正常提交。错误单元格有角标，选中后显示解释及「编辑公式」按钮；悬停可查看原公式和原因。能够定位时，还会显示出错的上游单元格或循环引用路径。追踪有数量上限，大量依赖不会阻塞界面。

批量粘贴保留所有公式，不逐个弹窗；状态栏汇总本次粘贴中的公式错误数，选中错误单元格即可继续检查。打开已有工作簿同样不逐格弹窗。

## 函数库与兼容范围

`fx` 函数库支持按名称或用途搜索，并可按统计、逻辑、文本、数学、查找、日期分类。每个函数都有参数说明和公式示例。示例可选择复制；「插入」只填入函数入口，填写并提交后才修改单元格。

目录覆盖引擎实际支持的 47 个函数名，包含 CONCATENATE 兼容名称。当前兼容范围包括：

- IF 需要填写三个参数。
- XLOOKUP 支持前五个参数，暂不支持第六个 `search_mode`。
- DATEDIF 支持 `"Y"`、`"M"`、`"D"`。
- TRIM 当前去除首尾空白，保留文本内部空格。
- 使用 `A2:A100` 形式的区域；当前不支持 `A:A`、跨 Sheet 引用和 Excel 的全部函数。

## 固定公式栏与结果预览

表格上方的公式栏显示当前地址和完整内容。输入后标记「草稿未提交」；Enter 或 ✓ 确认，Esc 或 ✕ 取消。单元格内输入与公式栏同步，也可在公式栏继续修改未完成的单元格草稿。确认前不会改变原值，取消也不会产生撤销记录。

公式栏下方在短暂停顿后显示预计结果或错误解释。计算在后台进行，预览不写入数据、不登记公式、不产生撤销记录；输入或数据变化后，旧结果作废。引用超过 10,000 个单元格时暂停自动计算，点击「计算预览」才执行，避免连续输入时反复扫描大表。

## 参数填写向导

点击公式栏的「参数向导」，按项填写 IF、SUMIFS、XLOOKUP 等函数。每个参数都有说明，可选参数会标明；多条件函数可以增加或移除一组条件。

点击「选取区域」后，向导暂时收起，在表格拖选后松开鼠标即可返回；Esc 取消选取。选区引用填入对应参数，源单元格和数据保持不变。「填入公式」只生成草稿，确认提交才修改单元格。已有函数的参数可带入继续修改。

## 错误定位

选中错误公式时，说明中可点击上游出错地址或循环引用路径跳转并滚动到相关单元格。公式栏的 ↩ 可返回原出错公式。定位只改变选区，不修改数据。搜索依赖和错误区域有数量上限。

## 草稿与单元格内容面板

长公式也可以在「单元格内容」面板编辑，共用补全、参数和诊断提示。公式输入期间不会自动重算，Enter 检查并提交；普通文本保留原有延迟保存行为。

切换单元格或 Sheet、保存、关闭前，会处理未提交的输入。完整合法的输入正常提交；公式尚未完成或存在语法问题时，明确提供三种选择：

- **继续编辑**：取消本次切换、保存或关闭，保留草稿与原单元格。
- **放弃草稿**：恢复原值，再继续操作。
- **保留为错误公式**：只有明确选择后才保存错误原文，便于稍后修改。

默认选择「继续编辑」。此规则同时覆盖单元格编辑器、固定公式栏和右侧内容面板；自动保存遇到草稿会延后，不会弹窗打断输入。

## 验证

`tests/test_formula_assistant.py` 覆盖函数目录与引擎一致性、嵌套参数、引号转义、中途编辑、输入法、补全、修正、撤销、点选引用、F4、预览面板、函数库和错误定位。自动弹出测试使用真实按键并等待事件循环，不直接调用弹层显示；另覆盖快速输入后立即按 Tab，确保使用最新输入进行补全。

`scripts/check_formula_assistant.py --output-dir build/formula-assistant` 使用隔离配置和合成数据检查中英文、深浅主题及宽窄窗口，并保存截图。macOS 可添加 `--platform cocoa`；Linux 原生检查使用 `--platform xcb`，已加入 CI 的正常缩放和 150% 缩放检查。输入分析不访问单元格值，也不会触发工作簿计算。

实际打包程序也包含内部验证入口：`SmartTableHub --smoke-formulas <输出目录>`。它用隔离配置和合成数据实际发送键盘、鼠标事件，检查自动纠错、公式栏预览、向导选区、错误跳转与草稿确认，输出截图和 `report.json`；不会打开真实工作簿。三平台发布流水线均要求这项检查成功才上传安装包。Mac 上可用 `QT_QPA_PLATFORM=cocoa` 检查原生窗口。
